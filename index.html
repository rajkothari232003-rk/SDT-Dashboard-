Execution P/L - signal vs actual fill (today)

Checking Zerodha connection...
On Run, the app fetches the selected futures contract's 1-minute candle close at the alert's timestamp from Zerodha (up to 40 rows per run - press Run again for the rest). Then type your actual trade price in My Price; Fut @ Signal and Exec P/L are editable/recalculated. Green + = execution profit (bought below / sold above the signal), red - = execution loss. With the webhook active and your daily Kite login done, Fut @ Signal is captured live at the moment each alert arrives (second-accurate); Run only back-fills rows the live capture missed or refreshes rows after changing futures month. Activate the API in Settings first.

Download data

Positions snapshot - end of day / next morning

Export downloads today's open positions (account, stock, indicator, TF, side, qty, average price, Total Qty) as a CSV. Import loads that file back as opening balances - each row becomes an executed trade at its average price. Legs that already hold an open position are skipped automatically, so importing twice can't double your book.
One .xlsx file with separate formatted sheets: Trade Log (every alert with Qty, prices, Executed, Exec P/L %), Positions (net per leg for the range), Execution P-L (with weighted-average summary), and Alert Creator History. Leave "To" empty for a single day. The tabs above show only today's data - everything older is stored in the background and downloadable here.

Zerodha sessions expire every day, so connect once each morning before using the Execution Loss tab. If your Kite app's Redirect URL is set to this dashboard's URL (- ), the connection completes automatically after login - this also pre-loads futures contracts so webhook alerts get their live signal price stamped instantly all day. Otherwise, copy the request_token from the redirected URL and paste it below.
Note: Kite Connect is a paid Zerodha product and minute-candle history needs their Historical Data add-on - check current pricing on developers.kite.trade. Keys are stored only inside this Apps Script project in your own Google account.
